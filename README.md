# nhf-phieu-in

Trang in A4 "Phiếu gửi hàng" cho Lark Base.

Lark Base dùng formula `ENCODEURL` ghép dữ liệu đơn vào phần `#` của link
`phieu.html#ma=...&nn=...&dt=...&dc=...&gc=...&ks=...&nl=...&sp=Tên~SL|Tên~SL`,
nút "In phiếu" (Button → Open Link) mở trang này. Dữ liệu chỉ nằm trên link,
không được gửi lên server và không lưu trong repo.
